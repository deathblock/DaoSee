# DaoSee

Builds transparent dashboards for cryptocurrency investors to track prices, orders, and market news in real time.

The key benefits of using DaoSee include:

- Builds transparent dashboards for cryptocurrency
- investors to track prices, orders,
- and market news in real

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoSee.git`
2. `cd DaoSee`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DaoSee, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
